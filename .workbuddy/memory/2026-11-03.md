
## 接入 AI 流式对话：修复 3 处报错 + 链路验证

用户按上一轮给的代码拼接后启动报错。逐个定位修复：

1. **`Chat.vue` 语法错误**（前端 build 挂在 `send()` 第 460 行）：新 `send()` 已完整插入，但旧函数体残留了 35 行（第 457–493 行），成了没有函数头的孤立代码块。删除残留。
   → 教训沿用：整块替换函数时，旧块可能没被完全覆盖，替换后必须 build 一次。
2. **`AiProperties.java` 第 8 行**：`@ConfigurationProperties(prefix = "ai"),` 注解末尾多了逗号。删掉。
3. **`AiChatService.java`**：`com.fasterxml.jackson.databind` 包不存在。**Spring Boot 4 已切到 Jackson 3（3.1.7），包名整体迁移到 `tools.jackson`**：
   - `com.fasterxml.jackson.databind.ObjectMapper` → `tools.jackson.databind.ObjectMapper`
   - `com.fasterxml.jackson.databind.JsonNode` → `tools.jackson.databind.JsonNode`
   - 自动配置注册的 bean 是 `tools.jackson.databind.json.JsonMapper`（`extends ObjectMapper`），按类型注入 `ObjectMapper` 仍可命中；`readTree`/`writeValueAsString` 签名不变，异常改抛 unchecked `JacksonException`。

**环境坑（非代码问题）**：本机 shell 环境有 `SERVER__PORT=52987`（WorkBuddy 沙箱注入），Spring Boot relaxed binding 把它当 `server.port`，覆盖 yml 的 8080，且该端口被 WorkBuddy 占用 → `Port 52987 was already in use`。用 `env -u SERVER__PORT mvn spring-boot:run` 后正常起在 8080。**用户从 IDEA 启动不会有此问题**。

**链路验证**（后端无 key + 前端 USE_MOCK=false）：
- `curl -sN POST /api/ai/chat/stream` → `data:{"error":"后端未配置 AI_API_KEY，请先在环境变量里设置"}`，SSE 帧格式正确
- `tools/verify-ai-stream.js`：请求 200、页面弹出同一条错误提示、用户气泡保留 + AI 气泡走兜底文案、会话自动入历史、无 JS 报错（404 仅 favicon）
- 前端 build 通过，Chat-DT8psMsa.js 10.08 kB

**结论**：前端→Vite 代理→后端→SSE→前端解析 全通，只差真实 API key。待办：用户配 `AI_API_KEY` 环境变量后重启后端即可逐字输出。
