## 概念答疑（用户问生命周期）
- 用户理解偏差：以为生命周期只是"启动时的运行顺序"，并以为启动后有独立的"预运行"阶段。
- 澄清：Vue3 没有独立"预运行"阶段，感觉上的预运行就是 `setup`——响应式已建立、DOM 尚未创建。分界线是 `mounted`：之前只有数据，之后才有 DOM。
- Vue2 教程里的 `created()` 在 Vue3 里就等于 `setup` 的位置，这是看旧教程最容易错位的地方。
- 结论：`el-tree` 数据是响应式的，赋值即渲染，不需要等 `mounted`；必须放 `mounted` 的只有需要真实 DOM 的东西（ECharts init、量尺寸、DOM 类第三方库）。

## 概念答疑（请求写在哪）
- 用户问：`onMounted` 是不是页面一运行就自动取数、不用点击/刷新？其他查询功能就不用写生命周期？
- 答案框架（已讲给用户，值得沉淀）：判断标准不是"查询 vs 非查询"，而是**触发者是谁**。
  - 自动发生（进页面就要有）→ 生命周期（setup / onMounted）
  - 用户动作触发（点查询、翻页、点树节点、输入搜索）→ 事件处理函数
  - 关键结构：**一个 `loadArticles()` 被两处共用**（首次 + 再次），函数与触发时机分离，禁止复制两份逻辑。
- 两个坑：① `keep-alive` 下 `onMounted` 只跑一次，回来要用 `onActivated`；② 条件变化必须重置 `page`，否则停在越界页。
- 刷新页面 = 组件重建 = `onMounted` 必然再跑，不用单独处理。

## 代码阅读页生成器（用户要求"把代码生成 html 看"）
- 新工具 `.workbuddy/tools/make-code-html.js`：读源文件 → 自动 HTML 转义 + 逐行语法高亮 + 行号，产出**自包含单文件 HTML**（无 CDN，离线可开）。
  - 用法：`node .workbuddy/tools/make-code-html.js <out.html>`
  - 高亮策略：一次性大正则匹配「注释/字符串」优先，其余段再匹配标签、`v-*` 指令、`@事件`、关键字、数字；**逐行处理 + `inBlock` 状态**处理跨行块注释（否则 span 跨行断裂、HTML 失效）。
  - vue 文件用 `indexOf('<template>') / '<script setup>' / '<style scoped>'` 三处定位切段，**不能用正则匹配 `<\/template>`**（内层 `<template #default>` 会提前截断）。
  - 分段顺序 `template → script → style → 头部契约`，**默认选中 script**（索引 1）；首版默认展示 59 行头部注释，首屏全是注释看不到代码，被自己发现并修正。
- 产出：`.workbuddy/previews/code-knowledge.html`（92 KB / 706 行），移动端截图 `code-1.png`、`code-2.png`，桌面 `code-desktop.png`。
- Escaping 要点：文本节点只需转义 `&` `<` `>`，`>` 其实可省但统一转更安全；`&&` 必须写成 `&amp;&amp;`。
