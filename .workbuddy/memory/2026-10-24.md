## 修复 vue-router 接入报错（23:10）

- 用户报错：`Failed to resolve import "src/router/index.js" from "src/main.js"`。
- 根因链（4 处，逐个会连环报错）：
  1. `main.js` 写成裸模块名 `'src/router/index.js'`（无 `./` / `@/`），Vite 当 npm 包解析 → 直接报此错。改为 `'./router/index.js'`。
  2. `vue-router` 从未加入 package.json / node_modules → 修完路径立刻报找不到 vue-router。已加 `^5.4.0`（vue-router 5 为当前最新），`npm install` 通过。

- 另加 `/` → `/back` 重定向，避免根路径空白。
