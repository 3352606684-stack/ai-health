## 23:30 登录/注册共用布局改造（方案 B：品牌区上移布局层）
- 起因：注册页 UI 与登录页左半区完全重复，用户希望"点击登录/注册切换时只变右半区，视觉顺滑"。
- 用户最初设想是「抽 BrandPanel 组件，两页各自嵌套」。**结论：不够**。login.vue ↔ register.vue 是两个不同组件类型，切换时整棵子树销毁重建，左半区会跟着重建（渐变/SVG 重绘，会闪）。
- 采用**方案 B：把品牌区上移到 `component/Authlayout.vue`（布局路由），router-view 只装右半区**。布局路由切换子路由时不卸载，左半区 DOM 完全常驻。
- 顺带解决两处"跳"：
  1. 右半区宽度统一 320px（原登录 300 / 注册约 328，切换会跳宽度）
  2. `.auth-body` 改 `align-items: flex-start` + `padding-top: 8vh`，**不用 center**。两页表单高度差很大，垂直居中会让标题上下跳；固定上边距后两页标题实测都在 y=72px，差 0。
- 表单骨架样式（`.form-inner/.form-title/.form-sub/.field-label/.req/.field-input/.submit/.foot`）用 `:deep()` 从 Authlayout 下发，两个页面**不再写 style**。改一次两页同步。
- 文件改动：
  - `component/Authlayout.vue` 12 行 → 约 200 行（品牌区 + auth-body + 共用表单样式 + 860px 窄屏隐藏品牌区）
  - `views/login.vue` 278 行 → 约 120 行（删品牌区与外层 flex，style 块整块删除）
  - `views/register.vue` 6 行空壳 → 完整注册页（6 字段 + 校验 + 模拟唯一性校验）
- 注册页校验：账号/邮箱必填、邮箱正则、手机号选填但需合法、密码≥6、两次一致；用 ElMessage toast（与登录页一致，不引入 el-form rules）。
- 注册成功 → `router.push({ path:'/auth/login', query:{ account } })`，登录页读 `route.query.account` 预填。
- `login.vue` 顺手加固：`(u.email || '').toLowerCase()`，防 ADMIN_DATA 缺 email 时抛错。
